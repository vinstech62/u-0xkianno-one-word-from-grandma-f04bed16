The one word a grandma would text about AI.

> Robit

Her own spelling of "robot": warm, a little baffled, funny with no caption needed, tied squarely to robots and AI, and fresher than the correctly spelled obvious pick — while still instantly readable.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic: it always writes the same single word (`Robit`, 5 characters, 5 bytes UTF-8) to `/output/entry.txt`. No input, no network, no randomness.
